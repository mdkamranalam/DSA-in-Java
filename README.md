# DSA in Java

A collection of Data Structures and Algorithms implemented in Java.

This repository contains solutions, implementations, and problem-solving patterns commonly used in coding interviews, competitive programming, and software engineering preparation.

---

### Basics
- Variables
- Loops
- Functions
- Arrays
- Time & Space Complexity

### Mathematics
- Prime Numbers
- GCD / LCM
- Fast Exponentiation
- Number Theory Basics

### Bit Manipulation
- Bitwise Operators
- Set / Unset Bits
- Power of Two
- XOR Tricks

### Sorting
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort

### Linked List
- Singly Linked List
- Doubly Linked List
- Circular Linked List
- Common Interview Problems

### Recursion & Backtracking
- Permutations

- Sudoku Solver

### DSA Patterns
- Two Pointers
- Sliding Window
- Fast & Slow Pointers
- Binary Search Pattern
- Prefix Sum
- Greedy Techniques

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/<your-username>/DSAinJava.git
cd DSAinJava
```

### Run

Compile:

```bash
javac Main.java
```

Execute:

```bash
java Main
```

Or simply run the desired class directly from IntelliJ IDEA.
